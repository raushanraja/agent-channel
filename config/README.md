# Agent configuration snippets

This directory holds ready-to-use configuration snippets for wiring `chan` into
different coding agents. Copy or merge the relevant snippet into your agent's own
config location; the snippets do not overwrite personal settings.

- `opencode.mcp.json` — MCP server entry for OpenCode
- `opencode.plugin.ts` — optional auto-pull plugin (same as `orchestracon/plugins/chan-auto-pull.ts`)
- `claude-desktop.mcp.json` — Claude Desktop MCP entry
- `codex.config.toml` — Codex MCP server snippet
